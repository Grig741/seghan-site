Какие данные мы храним

Для приглашения: имена хозяев события, дату, место, текст и выбранное оформление. Для ответов гостей: имя, придёт ли гость, сколько взрослых и детей. Если хозяева добавили список гостей, ещё имена и, по желанию, телефоны, чтобы отправить личную ссылку.

Эти данные видят только хозяева события по своей ссылке управления и мы, чтобы помочь с приглашением. Партнёр, подаривший сертификат, видит только общие числа, без имён гостей. Мы не продаём и не передаём данные третьим лицам.

Через 90 дней после события список гостей и их телефоны можно удалить по просьбе хозяев. Чтобы удалить данные раньше, напишите нам в Telegram.

Мы не используем рекламные трекеры. В браузере гостя хранится только его ответ, чтобы его можно было изменить.
